# Sam 日程与原生活动

本轮把 Sam 作为第一个“到日程点后执行对应活动”的角色接入。范围是未婚普通日程、天气、季节、体检与工作地点变更；婚后、姜岛和节日点位继续排除。原版依据为本地 1.6.15 日程、动画定义和人物帧；原版资料不是构建依赖。

2026-09-10 通用运行时修订：世界锚点分支已经统一经过家具接近点解析，并通过服务器专项测试；活动转由 `NpcScheduleActivity` 与通用活动数据驱动。本文继续记录已审批的内容规格。共享底层、验证结果与支撑状态的碰撞体边界见 [NPC 通用运行系统](npc-runtime-architecture.md)。

## 配置与选择规则

- 正式日程：`src/main/resources/data/stardewcraft/npc/schedules/sam.json`。
- 正式坐标：`npc_route_points.json` 中的 `sam_schedule_01` 等 25 个点，保留用户提供的原编号与方向。坐标审批原件在 `scripts/data/sam_schedule_point_approvals.json`。
- 正式日程的 `_selection_rules` 声明 Sam 的优先级（`SamSchedulePolicy` 仅保留为旧调用兼容与回归对照）：第一年绿雨 → 秋 11 体检 → 9/23 日条件 → 普通雨天 → 星期 → 季节。六心是门槛；Penny 达到六心时，该日期分支回退到 spring。
- 一个世界只有一位 Sam；好感条件采用所有已保存玩家中的最高值，所有玩家看到同一条日程。雨天两方案以世界种子和绝对日期稳定选择，同一天不会每次刷新重抽。
- 工作仍先去 Joja。任何玩家见过原版关闭事件 `191393` 后，工作点替换为博物馆，继续扫地。不能用“社区中心已完成”笼统代替关闭条件，因为 Joja 路线也可能设置该标记。
- 每套普通日程补充零点睡眠节点，覆盖起床前和跨日时段。Sam 已在同一张床睡眠时，不因日期或日程键改变而重播上床。

## 动作生命周期

`SamScheduleActivity` 管理接近／对齐、进入、持续、退出。共享事件只在状态变化时同步，包含行为、点位、开始时刻、退出时刻、家具锚点和朝向；晚加入观察的客户端也按服务器时刻采样。

进入和退出期间锁住旧移动与朝向控制器。点击聊天后，先完成当前进入段，再退出动作，最后调用已有的自然转头／转身聊天流程。日程换点、家具消失或朝向改变也会结束动作。退出完成才释放寻路。最后几厘米对齐有碰撞检测和超时重试，不能无限卡住移动所有权。

站立道具动作使用 0.8 秒收放势混合；收势保留被打断时的演奏相位。吉他、掌机和扫帚按前臂的完整矩阵保持单手接触，道具短暂淡入／淡出，音符不在收势阶段悬留。这是本模组的动作衔接，并非原版已有的取物、放回储物处动作。

餐椅进入／退出各 1.6 秒；睡眠进入 5.2 秒、退出 5.4 秒。床的进入段包含已经认可的床沿支撑过程，但床沿坐不作为独立日程活动。睡眠不调用玩家睡觉机制，不参与睡眠投票。NPC 本身仍由现有 SpawnManager 管理；服务器重启后按当前日程恢复接近与进入，未另行开启实体区块存档。

## 家具坐标与接触

- 5 号椅子 `(-8,39,30)`；6 号床 `(-9,39,26)`。二者均是家具方块坐标。
- `SamSupportTarget` 从实际方块解析主块和朝向。床可以指向任意组成格，不要求用户再提供头部方向。
- 寻路终点在家具旁。模型按家具锚点绘制，实体保持在接近点；退出端重新与实体站姿重合。床边的接近点也是当前实体交互位置。
- 椅子按 9/16 高的实际座面适配，腿保持刚性长度；膝盖弯曲后脚自然悬在椅前，入座前延后抬脚。袖口与夹克、双腿采用完整体积检查。
- 家具被玩家占用时不开始活动；Sam 占用餐椅时，玩家不能同时骑上该椅子的座位实体。家具缺失时不会在空中坐下或躺下。

## 验证与游戏内验收

已进行 Blockbench 正式资产重载和实际家具预览。最终图保存在 `assets-src/npc/sam/previews/schedule-chair.png` 与 `schedule-sleep.png`。

开发验证：`./gradlew classes checkSamSchedule`。定向检查覆盖日期优先级、好感门槛、雨天稳定性、七类行为别名与资源、2661 个退出过渡采样及姿势交接、354 个餐椅袖口／夹克／腿部体积采样。该检查不读取原版源文件、试作目录或个人绝对路径。

本轮未启动额外游戏客户端，编译和预览不能证明实际地图全部路线可达。重启开发游戏后建议按下表观察，日程时间是开始前往目标的时间，长路线需要留出走路时间。

| 场景 | 重点时间与检查 |
| --- | --- |
| 普通周五 | 10:00 家中吉他 → 11:00 镇上滑板 → 15:00 酒吧手势 → 21:20 回床睡觉 |
| 普通周一／周三 | 11:00 Joja 扫地；关闭事件完成后为博物馆；16:00 下班回家 |
| 普通周六 | 11:00 镇上掌机 → 12:30 家中吉他；19:40 回床 |
| 普通春季日 | 18:30 木制餐椅 → 21:00 床；再观察次日上午起床 |
| 雨天方案一 | 15:00 厨房掌机 → 17:00 书架 → 18:30 餐椅 → 20:00 床 |
| 秋 11 | 11:30 医院候诊掌机 → 13:30 诊室 → 16:00 镇上 → 21:00 床 |

同时检查：动作中聊天后再恢复、日程换点时先收势、两位玩家同时观察、椅子被占用、床椅朝向改变。现有节日服务仍独立运行；本轮不重写节日系统。
