# 沙滩补给箱

## 当前实现

- 方块与物品：`stardewcraft:supply_crate`，自然分类，三个外观用 `variant=0/1/2` 保存。物品栏分别显示三种造型，选取方块保留造型；无指定外观的箱子放置时等概率选一种。
- 使用水面放置物品，只能放在有空位的静水水面上方一格；不替换原有水。箱子连续上下浮动并轻微摇摆，打碎时七块箱板散开。
- 斧、镐、锄、近战武器和镰刀可以打碎。原作耐久为 3，每次伤害为工具升级级别加 1；这里适配 MC 按住挖掘，以每次 12 tick 换算所需次数。普通工具、铜工具、钢及更高工具分别需要 3、2、1 次对应时长。
- 奖励在服务端正常生存破坏时结算一次。创造模式、移除支撑水源、爆炸、活塞等非玩家工具破坏不提供奖励，也不掉落可再次开出的箱子。精准采集和时运不改变奖励。
- 箱子外观不影响奖励。奖励在破坏时读取全局星露谷日期，因此旧箱子会随日期进入新档位。
- 无合成或购买配方。本次只接入方块、物品和破坏奖励，没有修改农场生成。

## 原版奖励核对

依据原作 `Object.performToolAction` 的 SupplyCrate 分支（物品 922、923、924）。三档分别有 7、10、9 个等概率分支；下列数量均包含端点。

- 第一档：混合种子 3–5；优质保湿土壤 5–7；晶球 2–4；救生汉堡 1–2；咖啡 1–2；樱桃炸弹 3–5；樱桃炸弹 3–5。炸弹重复分支保留，概率为 2/7。
- 第二档：混合种子 3–5；优质保湿土壤 5–7；万象晶球 2–4；三倍浓缩咖啡 1–2；巨无霸餐 1–2；大麦粉 4–7；油 2–4；糖 4–7；炸弹 3–5；混合花卉种子 4–5。
- 第三档：混合种子 3–5；顶级保湿土壤 5–7；万象晶球 2–4；三倍浓缩咖啡 2–3；香蕉布丁或芒果糯米饭（二选一各半，1–2）；大麦粉 4–7 **加** 油 2–4 **加** 糖 4–7；古物宝箱 2；超级炸弹 3–5；混合花卉种子 5。

掉落通过原版物品 key 映射到模组物品，未以原版 MC 物品代替。随机种子按世界及平面坐标固定，奖励池、分支权重和数量对应原作；不承诺 Java 与原作 .NET 随机序列逐次相同。

本次补齐缺失的 `mixed_flower_seeds`，使用原版 16×16 物品图标。春季随机郁金香/蓝爵，夏季夏季亮片/虞美人/向日葵，秋季向日葵/玫瑰仙子；冬季先随机选择春夏秋，再抽取该季节花种，沿用现有花种的季节、温室与本模组耕地限制。未改动其他系统原有的混合种子替代规则。
