# 沙子与沙质耕地

## 方块与季节

- `stardewcraft:sand`：沙子，自然分类。完整方块，作为地图地表保持稳定，不受重力下落；四季六面统一选择对应材质。
- `stardewcraft:sandy_farmland`：沙质耕地，自然分类。继承现有 `TerrainFarmlandBlock` / 原版 `FarmBlock`，保留原版 15/16 高度、作物支持与 0–7 湿度。
- 春夏秋冬各有干、湿材质。夏季暖金黄，秋季暖桃赭；冬季重新组织霜面和冰沟，没有裂纹。全部基础贴图原生 16×16，端面与侧面沿口对应顶部，垄沟沿铺设方向连续。
- 季节仅影响客户端材质选择，不改已存方块、湿度或肥料。手持、物品栏与掉落实体也选当前季节的孤立方块模型。

## 耕种与浇水

- 原版锄头和模组锄头均通过 `HOE_TILL` 将本模组沙子耕成沙质耕地；盖住的沙子不可耕。原版沙子、游乐区沙地以及草地保持各自既有规则。
- 水壶、雨水与现有跨夜结算适用。星露谷维度仍由该维度的天气与日结算决定水分；其他维度沿用原版耕地补水和随机刻行为。
- 沙子与沙质耕地不能放本模组洒水器；从相邻普通土上喷水也会跳过沙质耕地。普通耕地的灌溉不受影响。这对应本地原作 `源文件/StardewValley/Object.cs` 中放置及 `ApplySprinkler` 对 `NoSprinklers` 的两处检查。
- 九种现有肥料全部接入，使用现有施肥、作物效果、持久化、保水与清理机制。图案嵌入四季干湿顶面，沿口不跨出肥料颗粒，也不额外占用种植格。
- 沙子及沙质耕地普通挖掘都掉落沙子。退耕、外维度踩踏回退、放置失败回退、公共区域日结算和农场碎屑覆盖都保留沙质基底。
- 原版 `maintains_farmland` 标签下的作物与模组作物一样保护耕地，不会被夜间结算误判为空地。
- 海滩采集物与远古斑点的原有沙地判断包含新沙子，生成仍由原有区域映射控制；耕地不进入远古斑点可生成地表。

## 连接

**深色草地 ＞ 草地 ＞ 湿耕地（普通／沙质）＞ 干耕地（普通／沙质）＞ 泥土 ＞ 沙子 ＞ 岩壁。**

- 普通与沙质耕地同级时保留各自材质，垄沟对齐；换土质不会触发收沟。湿邻居使干面的边缘过渡到接收方自身的湿润色，不传递实际浇水状态。
- 接壤未耕泥土或沙子时，沟纹在耕地内部收进自身基底。垄沟和肥料不向未耕地扩散。
- 泥土在沙子边缘形成窄土边，沙子与岩壁接触时形成积沙边；草地与深色草地按更高优先级覆盖。建筑铺地仍使用各自的连接体系。
- 顶部、侧面、墙地折角共用现有原生像素采样。耕地下凹一像素，覆盖层随之降低；几何检测不跨过悬空空隙。建筑模板、半砖和楼梯借材质时沿用实际暴露面的裁切。
- 连接通过裁切并替换原表面像素完成，肥料也是表面的一部分，不叠加整块透明渲染层。

## 资源与验证

生产材质：`src/main/resources/assets/stardewcraft/textures/block/terrain/{sand,sandy_farmland,fertilized/sandy}`。

`scripts/generate_sandy_farmland.py` 只读取受版本管理的生产材质及既有肥料绘画方案，生成 80 张连接贴图、72 张肥料贴图与 4 张肥料图集。源画稿和可编辑模型在 `assets-src/blocks/sandy_farmland/`。

本轮验证：

- `./gradlew classes checkTranslations`：通过。
- `./gradlew runGameTestServer -PgameTestNamespaces=stardewcraft_sandy_soil`：4 项必需测试全部通过，覆盖锄地、作物支持、形状、掉落、灌溉、施肥保存、夜间保水、回退与连接优先级。
- `python3 scripts/verify_sandy_farmland.py`：四季、干湿、肥料、沿口接缝、96 个模型的材质／粒子引用、物品与掉落检查通过。
- `python3 scripts/verify_farmland_quads.py`：4418 组干湿边缘组合无漏面、重复面或 UV 拉伸。
- 八个干湿源模型已在 Blockbench 重载检查；四季混铺截图保存在源资产目录。本任务模型标签已关闭。

以上不是 Minecraft 客户端视觉验收。客户端重启后，检查季节切换、混铺边缘和实体投影；本轮未打包 JAR。
