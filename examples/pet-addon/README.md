# 独立宠物附属示例

这是独立 NeoForge 工程，本体不编译、不注册这里的品种。装上后，新农场问卷中增加“森林伙伴”；示例复用已有橘猫模型、动画和图标，证明注册入口，不是浣熊成品。

只使用 `com.stardew.craft.api.v1.pet` 的四个公开类型，没有访问 PetService、PetVariant 或本体实体实现。新品种可免费开局选择，示例关闭了商店购买；照顾、水碗、抚摸后管理和名字保存由本体承接。

在仓库根目录先运行 `./gradlew classes`，再运行 `./gradlew -p examples/pet-addon classes`。示例编译直接读取本体当前 classes，不要求构建 JAR。外部开发可传 `-PstardewcraftJar=/绝对路径/匹配的本体.jar`。

实际安装须同时在客户端与服务端放入匹配的本体和附属。当前接口在 0.6.1 首次发布，仍属实验接口；登录时本体会比对宠物定义。示例工程不会自动安装进现有游戏目录。

制作浣熊附属时另建 `raccoon_pet` 工程，使用自己的模型、材质、图标、行为图与翻译。详细资源契约见仓库 `docs/pet-addon-api.md`。
